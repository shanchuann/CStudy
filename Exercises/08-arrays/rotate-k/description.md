# 三次翻转循环左移

## 题目描述

读入 n 个整数，把它们循环左移 k 位后输出。循环左移 k 位表示原来的第 k 个元素移动到数组开头，前 k 个元素依次接到数组末尾。

要求使用三次翻转法在原地完成移动：先翻转前 k 个元素，再翻转剩下的 n-k 个元素，最后翻转整个数组。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 1000）。

第二行一个整数 k（0 ≤ k < n）。

第三行 n 个整数，用空格分隔。

## 输出格式

输出一行 n 个整数，为循环左移后的数组，相邻整数之间用一个空格分隔，行末不要多余空格。

## 示例

**示例 1**

输入：

```text
5
2
1 2 3 4 5
```

输出：

```text
3 4 5 1 2
```

**示例 2**

输入：

```text
3
2
1 2 3
```

输出：

```text
3 1 2
```

## 知识点

- 数组元素的原地交换
- 三次翻转法实现循环移位：翻转前 k 个、翻转后 n-k 个、再翻转整个数组
- 循环左移与下标的对应关系

## 提示

- 先把 a[0..k-1] 翻转，再把 a[k..n-1] 翻转，最后把整个数组翻转。
- 写一个 reverse_range(a, left, right) 辅助函数可以避免重复代码。
- k 为 0 时不需要做任何移动，直接输出原数组即可。
