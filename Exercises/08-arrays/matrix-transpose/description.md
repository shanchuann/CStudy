# 二维数组转置

## 题目描述

读入一个 r 行 c 列的整数矩阵，输出它的转置矩阵。转置就是把第 i 行第 j 列的元素放到第 j 行第 i 列。

## 输入格式

第一行两个整数 r 和 c（1 ≤ r, c ≤ 20）。

接下来 r 行，每行 c 个整数，用空格分隔。

## 输出格式

输出 c 行，每行 r 个整数，为转置后的矩阵，数字之间用一个空格分隔，行末不要多余空格。

## 示例

**示例 1**

输入：

```text
2 3
1 2 3
4 5 6
```

输出：

```text
1 4
2 5
3 6
```

**示例 2**

输入：

```text
3 2
1 2
3 4
5 6
```

输出：

```text
1 3 5
2 4 6
```

## 知识点

- 二维数组的定义与 a[i][j] 的访问方式
- 转置矩阵把第 i 行第 j 列的元素放到第 j 行第 i 列
- 用嵌套循环按行列输出矩阵

## 提示

- 转置后共有 c 行、每行 r 个元素，外层循环控制列号 j，内层循环控制行号 i。
- 输出 a[i][j] 时注意不要写成 a[j][i]。
