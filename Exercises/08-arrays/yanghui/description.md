# 杨辉三角

## 题目描述

输出杨辉三角的前 n 行。杨辉三角每一行的首尾元素都是 1，其余元素等于上一行同一列元素与前一列元素之和。

教材提示可以用一维数组倒序更新，也可以用二维数组。

## 输入格式

一行一个整数 n（1 ≤ n ≤ 15）。

## 输出格式

输出 n 行，第 i 行是杨辉三角的第 i 行，数字之间用一个空格分隔，行末不要多余空格。

## 示例

**示例 1**

输入：

```text
3
```

输出：

```text
1
1 1
1 2 1
```

**示例 2**

输入：

```text
5
```

输出：

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

## 知识点

- 杨辉三角的递推关系：a[i][j] = a[i-1][j-1] + a[i-1][j]
- 用一维数组倒序更新，避免覆盖上一行还要用的值
- 嵌套循环控制行与列的输出

## 提示

- 一维数组只保存当前行，每进入新的一行时从右往左更新：row[j] = row[j] + row[j-1]。
- 从后往前更新是因为 row[j-1] 还是上一行的值，正好是递推需要的。
- 行末不要多输出空格。
