# 数组最大值

## 题目描述

读入 n 个整数，找出其中的最大值并输出。教材用数组保存一批同类型的数据，再用循环依次访问每个元素，这正是数组最基本的用法。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）。

第二行 n 个整数，用空格分隔。

## 输出格式

输出一个整数，即这 n 个数中的最大值。

## 示例

**示例 1**

输入：

```text
5
3 8 2 9 4
```

输出：

```text
9
```

**示例 2**

输入：

```text
3
-5 -2 -9
```

输出：

```text
-2
```

## 知识点

- 一维数组的定义、初始化与下标访问
- 用 for 循环遍历数组的每一个元素
- 最大值应初始化为第一个元素，而不是 0

## 提示

- 把 best 先设为 a[0]，再从 a[1] 开始逐个比较，这样数组全为负数时也能得到正确结果。
- n 至少为 1，所以 a[0] 一定存在。
