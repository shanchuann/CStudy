# 二分查找

## 题目描述

在一个严格递增的整数数组中查找目标值 target，返回它的下标（从 0 开始）；如果不存在则输出 -1。

请使用二分查找：每次取区间中点与 target 比较，根据大小关系把查找区间缩小一半。要求时间复杂度为 O(log n)。

## 输入格式

第一行两个整数 n 和 target（1 ≤ n ≤ 1000）。

第二行 n 个严格递增的整数，用空格分隔。

## 输出格式

输出一个整数：target 在数组中的下标，不存在时输出 -1。

## 示例

**示例 1**

输入：

```text
5 7
1 3 5 7 9
```

输出：

```text
3
```

**示例 2**

输入：

```text
4 6
1 3 5 7
```

输出：

```text
-1
```

## 知识点

- 有序数组上的二分查找，时间复杂度 O(log n)
- 区间不变量：目标值只可能在 [left, right] 内
- mid 的计算与区间的收缩方式

## 提示

- 循环条件是 left <= right；比较 a[mid] 与 target 后收缩区间。
- mid 写成 left + (right - left) / 2 可以避免 left + right 溢出。
- 数组严格递增，所以找到就可以直接返回。
