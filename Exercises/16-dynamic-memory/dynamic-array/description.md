# malloc 动态数组

## 题目描述

当数组长度要到运行时才知道时，可以用 malloc 在堆上申请 sizeof(int) * n 字节，把返回的指针当作 int 数组使用，最后用 free 释放。

请读入 n 和 n 个整数，用 malloc 申请数组保存它们，输出总和与平均值。

## 输入格式

第一行一个整数 n。

第二行 n 个整数，之间用空白分隔。

## 输出格式

输出一行：sum=<总和> avg=<平均值，保留两位小数>

## 数据范围

1 <= n <= 1000，每个整数 |a[i]| <= 10000，总和在 int 范围内。

## 示例

**示例 1**

输入：

```text
3
1 2 3
```

输出：

```text
sum=6 avg=2.00
```

**示例 2**

输入：

```text
4
1 1 1 2
```

输出：

```text
sum=5 avg=1.25
```

## 知识点

- malloc(sizeof(int) * n) 申请 n 个 int 的数组
- 元素个数与字节数分开计算
- 把 malloc 的返回值当作数组使用
- free 释放整个数组

## 提示

- 申请 sizeof(int) * (size_t)n 字节，返回的指针就能像 int 数组一样用 data[i] 访问。
- 平均值是 (double)sum / n，用 %.2f 保留两位小数。
