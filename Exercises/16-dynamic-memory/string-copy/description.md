# 动态字符串复制

## 题目描述

栈上数组的长度必须在编译期确定，要按运行时的实际长度保存字符串就得使用动态内存。malloc 从堆上申请一块内存，用完必须用 free 归还。

请读入一个单词，用 malloc 申请恰好能放下它的空间（strlen + 1 字节，多出的 1 字节放结尾的 '\0'），把单词复制进去并输出，最后释放内存。

## 输入格式

一行一个不含空白字符的单词，长度 1 到 100。

## 输出格式

输出一行：复制得到的字符串，内容与输入相同。

## 示例

**示例 1**

输入：

```text
cstudy
```

输出：

```text
cstudy
```

**示例 2**

输入：

```text
abcdefghij
```

输出：

```text
abcdefghij
```

## 知识点

- malloc 按字节数申请堆内存并返回 void *
- strlen + 1：多出的一个字节存放结尾的 '\0'
- 用 memcpy 复制字符串内容
- free 释放内存，避免内存泄漏

## 提示

- 先求 len = strlen(word)，再 malloc(len + 1) 字节。
- 复制时要把结尾的 '\0' 一起复制（memcpy 的长度是 len + 1），最后别忘了 free。
