# realloc 扩容

## 题目描述

realloc 可以在已有分配的基础上扩大或缩小内存块。用“容量不足时把容量翻倍”的策略，就能把任意多个输入读进一个动态数组，而不必预先知道个数。

请从标准输入一直读到 EOF，用一个初始容量为 2、容量不足时倍增的 int 数组保存所有整数，最后输出个数与总和。

## 输入格式

一行或多行整数，之间用空白分隔，直到文件结束（EOF）。整数个数为 1 到 1000。

## 输出格式

输出一行：count=<个数> sum=<总和>

## 数据范围

整数个数 1 到 1000，每个整数 |a[i]| <= 10000，总和在 int 范围内。

## 示例

**示例 1**

输入：

```text
1 2 3 4 5
```

输出：

```text
count=5 sum=15
```

**示例 2**

输入：

```text
7
```

输出：

```text
count=1 sum=7
```

## 知识点

- realloc 调整已分配内存块的大小
- 用临时指针接收 realloc 的返回值，成功后再赋回
- 容量与元素个数分开维护
- 容量不足时倍增的扩容策略

## 提示

- 初始容量为 2；每读到一个整数，如果 count == cap 就把容量翻倍并 realloc。
- realloc 失败会返回 NULL 且原内存仍然有效，所以要先存进临时指针再判断。
- 用 while (scanf("%d", &x) == 1) 一直读到 EOF。
