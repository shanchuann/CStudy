# 打字得分

## 题目描述

打字母游戏需要一个判定模块：把玩家输入的字符串与目标字符串逐位比较，统计相同位置字符相同的个数作为得分。本题实现这个计分模块。

## 输入格式

一行两个不含空白的字符串（长度 1..100），用空格分隔。

## 输出格式

一行：两个字符串在相同位置上字符相同的个数。

## 示例

**示例 1**

输入：

```text
hello healo
```

输出：

```text
4
```

**示例 2**

输入：

```text
abc abc
```

输出：

```text
3
```

## 知识点

- 逐字符比较
- 只比较两个字符串的公共长度
- 游戏计分逻辑

## 提示

- 先求两个字符串长度的较小值，再逐位比较。
