# 二维数组棋盘

## 题目描述

打字母 v1.0 的显示模块用二维数组表示画面：字母从上方下落，其余位置显示为点号。本题实现最小版本的显示模块。

## 输入格式

一行四个值：rows cols（1..20）、字母 ch、行号 r（0 <= r < rows），用空格分隔。

## 输出格式

输出 rows 行，每行 cols 个字符：第 r 行第 0 列是字母 ch，其余位置是点号。

## 示例

**示例 1**

输入：

```text
3 4 A 1
```

输出：

```text
....
A...
....
```

**示例 2**

输入：

```text
2 2 x 1
```

输出：

```text
..
x.
```

## 知识点

- 二维字符数组表示画面
- 坐标到数组下标的映射
- 显示模块与处理模块分离

## 提示

- 先把整个棋盘填成点号，再把字母放到第 r 行第 0 列。
- 字母用 %c 读取，格式串前面的空格会跳过空白。
