# 命中判定

## 题目描述

打字母游戏的处理模块需要判断玩家的按键是否与当前目标字母相同。本题实现这个判定。

## 输入格式

一行两个字符，用空格分隔：第一个是目标字母，第二个是玩家按键。

## 输出格式

相同输出 hit，不同输出 miss（区分大小写）。

## 示例

**示例 1**

输入：

```text
a a
```

输出：

```text
hit
```

**示例 2**

输入：

```text
a b
```

输出：

```text
miss
```

## 知识点

- 处理模块的按键判定
- 字符比较区分大小写
- 游戏状态的输入输出

## 提示

- 输入的两个字符用空格分隔，格式串写成两个 %c 即可。
