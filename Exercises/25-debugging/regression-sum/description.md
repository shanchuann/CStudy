# 边界回归测试

## 题目描述

教材用一段越界代码说明：把循环条件写成 i <= count 会多读一个元素，越界访问属于未定义行为，不能靠某次运行恰好正确的输出来判断程序是否正确。本题要求实现边界正确的求和函数。

## 输入格式

第一行整数 n（0 <= n <= 100）；n 大于 0 时第二行有 n 个整数，n = 0 时没有第二行。

## 输出格式

输出一行：sum=<总和>

## 示例

**示例 1**

输入：

```text
3
1 2 3
```

输出：

```text
sum=6
```

**示例 2**

输入：

```text
0
```

输出：

```text
sum=0
```

## 知识点

- 数组下标上界是 count - 1
- 循环不变量
- 用边界用例做回归测试

## 提示

- 循环条件写成 i < count，不要写成 i <= count。
