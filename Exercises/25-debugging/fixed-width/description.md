# 可移植类型与格式宏

## 题目描述

int、long 的宽度由实现决定，需要固定宽度时应使用 stdint.h，并用 inttypes.h 提供的格式宏打印，而不是写死 %d 或 %ld。

## 输入格式

无输入。

## 输出格式

输出两行：

uint32=4294967295

uint64=18446744073709551615

## 示例

**示例 1**

输出：

```text
uint32=4294967295
uint64=18446744073709551615
```

## 知识点

- 固定宽度类型 stdint.h
- 格式宏 PRIu32 / PRIu64
- 不要假设 int 的宽度

## 提示

- 用 UINT32_MAX、UINT64_MAX 与 PRIu32、PRIu64 拼接格式串。
