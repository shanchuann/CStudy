# 错误处理与资源释放

## 题目描述

读取数量 n，申请动态数组并读入 n 个整数求和。数量非法或分配失败时都不能让程序崩溃，而要输出 error；成功路径上必须释放内存。

## 输入格式

第一行一个整数 n；若 n 合法（1 <= n <= 100000），第二行有 n 个整数。

## 数据范围

每个整数的绝对值不超过 1000，因此总和不会超出 int 范围。

## 输出格式

成功时输出一行 sum=<总和>；n 超出范围或内存分配失败时输出 error。

## 示例

**示例 1**

输入：

```text
3
1 2 3
```

输出：

```text
sum=6
```

**示例 2**

输入：

```text
0
```

输出：

```text
error
```

## 知识点

- 先校验再分配
- malloc 返回值必须检查
- 所有路径都要释放内存
- 错误用输出报告

## 提示

- n 超出范围直接输出 error，不要继续申请内存。
- 分配失败同样输出 error。
