# 输入校验与断言的分工

## 题目描述

教材把两类检查分开：assert 用来描述程序员的假设（内部不变量），而用户输入、文件内容和命令行参数必须用普通条件判断校验。本题练习后者：对读到的整数做输入校验，并给出确定的输出。

## 输入格式

一行一个整数。

## 输出格式

若输入为正数输出 ok，否则输出 error。

## 示例

**示例 1**

输入：

```text
3
```

输出：

```text
ok
```

**示例 2**

输入：

```text
0
```

输出：

```text
error
```

## 知识点

- 用户输入必须用普通条件判断校验
- assert 描述程序员假设而不是校验外部输入
- 错误分支要有明确输出

## 提示

- 外部输入永远可能非法，用 if 判断并给出确定输出。
