# 结构体成绩平均值

## 题目描述

结构体把不同类型的数据组织成一个整体。本题用结构体保存一个学生的姓名和三门课成绩，再对成绩做计算。

结构体定义如下：

    struct Student {
        char name[32];
        double scores[3];
    };

读入一个学生的一条记录，计算三门成绩的平均值并输出。

## 输入格式

一行：姓名（不含空白字符，长度不超过 31）与三门成绩，之间用空白分隔。成绩为整数或小数。

## 输出格式

输出一行：平均分，保留两位小数。

## 数据范围

每门成绩是 0 到 100 之间的实数。

## 示例

**示例 1**

输入：

```text
Lin 80 90 100
```

输出：

```text
90.00
```

**示例 2**

输入：

```text
B 59.5 60 61
```

输出：

```text
60.17
```

## 知识点

- 结构体定义：数组成员 char name[32] 与 double scores[3]
- 结构体变量的定义与成员访问 s.name、s.scores[i]
- 在一条 scanf 中读取结构体的各个成员
- 用 %.2f 输出保留两位小数的平均值

## 提示

- 姓名与三门成绩可以在一条 scanf 里读完：scanf("%31s %lf %lf %lf", ...)。
- 59.5+60+61=180.5，平均 60.1666...，保留两位是 60.17。
