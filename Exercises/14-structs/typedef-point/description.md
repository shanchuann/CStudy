# typedef 与结构体指针

## 题目描述

typedef 可以给结构体类型起一个别名，之后声明变量时就不必再写 struct 关键字。指向结构体的指针用 -> 运算符访问成员。

结构体定义如下：

    typedef struct Point {
        double x;
        double y;
    } Point;

读入一个点的坐标，计算它到原点距离的平方 d2 = x * x + y * y。

## 输入格式

一行两个实数 x 与 y，之间用空白分隔。

## 输出格式

输出一行：d2=<距离的平方，保留两位小数>

## 数据范围

|x| 与 |y| 不超过 1000。

## 示例

**示例 1**

输入：

```text
3 4
```

输出：

```text
d2=25.00
```

**示例 2**

输入：

```text
1 1
```

输出：

```text
d2=2.00
```

## 知识点

- typedef 为结构体类型起别名，使用时省去 struct 关键字
- 结构体指针与 -> 运算符访问成员
- 用乘法和加法代替 math.h 求距离平方

## 提示

- d2 = ptr->x * ptr->x + ptr->y * ptr->y，不需要开方，也就用不上 math.h。
- 结构体指针的声明：Point *ptr = &p;
