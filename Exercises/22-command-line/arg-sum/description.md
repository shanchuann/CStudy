# 参数求和与校验

## 题目描述

命令行参数都是字符串，需要用 strtol 这类函数转换成数值。strtol 通过 end 指针告诉调用者解析停在了哪里：如果停下的位置不是字符串结尾，说明这个参数不合法。

程序要求：把每个命令行参数用 strtol 严格解析为 long，规则如下：

- 允许前导空白与正负号；
- 解析结束后只允许剩下空白字符，出现任何非空白字符都算非法；
- 数值溢出也算非法。

全部参数合法时输出它们的和；任一参数非法时输出 invalid；没有参数时输出 0。

## 输入格式

无标准输入，参数由命令行给出。

## 输出格式

输出一行：所有参数之和，或者 invalid。

## 数据范围

参数个数 0..100；每个合法参数的绝对值不超过 1000000，总和在 32 位 int 范围内。

## 示例

**示例 1**

命令行参数：

```text
1 2 3
```

输出：

```text
6
```

**示例 2**

命令行参数：

```text
1 x
```

输出：

```text
invalid
```

## 知识点

- strtol 的 end 指针与严格校验
- 参数非法时的错误处理
- 用 long long 累加避免中间结果溢出

## 提示

- strtol 之前把 errno 置 0，解析后检查 errno 是否为 ERANGE。
- end == text 表示一个数字都没解析出来。
- 把 end 之后的空白跳过，必须正好停在 '\0'。
