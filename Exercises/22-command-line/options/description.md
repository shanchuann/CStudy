# 选项解析

## 题目描述

命令行选项通常由“选项名 + 选项值”成对组成，解析时要检查每个选项后面是否真的有值，也要拒绝未知选项。

程序要求：支持选项 -n NAME 与 -a AGE，两者顺序任意，并且必须成对出现。以下情况都输出 invalid：

- 缺少 -n 或缺少 -a；
- 某个选项后面没有值；
- 出现未知选项；
- 同一个选项重复出现；
- 出现多余的参数。

全部合法时输出一行 name=<NAME> age=<AGE>。

## 输入格式

无标准输入，参数由命令行给出。

## 输出格式

输出一行：name=<NAME> age=<AGE>，或者 invalid。

## 数据范围

参数个数 0..10。

## 示例

**示例 1**

命令行参数：

```text
-n Lin -a 18
```

输出：

```text
name=Lin age=18
```

**示例 2**

命令行参数：

```text
-a 18 -n Lin
```

输出：

```text
name=Lin age=18
```

## 知识点

- 手动解析 argv 中的选项与选项值
- 参数边界检查（i + 1 >= argc）
- 解析逻辑与业务逻辑分离

## 提示

- 用 while 循环按步长 2 跳过“选项 + 值”，未知选项直接判非法。
- 两个选项都用指针记录是否出现过，最后检查都不为 NULL。
