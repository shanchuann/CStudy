# 子命令

## 题目描述

很多命令行工具用第一个参数作为子命令，后面的参数作为子命令自己的操作数。解析时要先校验参数个数，再把操作数转换成数值。

程序要求：支持三个子命令，a 与 b 都是 long：

- add a b：输出 a + b；
- mul a b：输出 a * b；
- max a b：输出 a 与 b 中较大的一个。

子命令未知、参数个数不对或参数非法时一律输出 unknown。

## 输入格式

无标准输入，参数由命令行给出。

## 输出格式

输出一行：计算结果，或者 unknown。

## 数据范围

a、b 解析后的绝对值不超过 1000，运算结果在 32 位 int 范围内。

## 示例

**示例 1**

命令行参数：

```text
add 3 4
```

输出：

```text
7
```

**示例 2**

命令行参数：

```text
mul 3 4
```

输出：

```text
12
```

## 知识点

- argv[1] 作为子命令的分派方式
- 参数个数校验（argc）
- strtol 严格校验与错误统一处理

## 提示

- 先检查 argc 是否等于 4，再解析 argv[2] 与 argv[3]。
- 用 strcmp 依次比较 argv[1] 与三个子命令名。
