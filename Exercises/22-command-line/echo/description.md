# 参数回显

## 题目描述

命令行参数通过 main 的 argc 与 argv 传入：argc 是参数个数（包含程序名），argv[0] 是程序名本身，真正的用户参数从 argv[1] 开始。

程序要求：把所有命令行参数（不含程序名）用单个空格连接后输出一行。没有任何参数时输出一个空行。

## 输入格式

无标准输入，参数由命令行给出。

## 输出格式

输出一行：参数之间用单个空格分隔。没有参数时输出空行。

## 数据范围

参数个数 0..10。

## 示例

**示例 1**

命令行参数：

```text
hello world
```

输出：

```text
hello world
```

**示例 2**

输出：

```text

```

## 知识点

- argc 与 argv 的含义
- argv[0] 是程序名，用户参数从 argv[1] 开始
- 遍历命令行参数

## 提示

- 循环从 i = 1 开始，到 i < argc 结束。
- 第一个参数前面不加空格，之后的每个参数前面先输出一个空格。
