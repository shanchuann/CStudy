# 文件存储

## 题目描述

成绩管理系统的存储模块把记录写成文本文件，每行一条：学号,姓名,成绩。程序启动时再读回这些记录。本题实现写入与读回两个方向，并统计记录数与最高分学号。

## 输入格式

第一行整数 n（1..100）；随后 n 行，每行形如 id,name,score，其中 id 为整数、name 不含空白、score 为一位小数。

## 输出格式

输出一行：count=<读回的记录数> top=<最高分学生的学号>

判题时程序在当前工作目录创建 students.txt，不需要其他文件。

## 示例

**示例 1**

输入：

```text
3
1,Lin,80.0
2,Mei,95.5
3,Kai,88.0
```

输出：

```text
count=3 top=2
```

## 知识点

- 文本格式一行一条记录：学号,姓名,成绩
- fprintf 写入与 fgets 读回
- 解析逗号分隔字段

## 提示

- 写入用 fprintf 配合 %d,%s,%.1f 与换行符。
- 读回时用 fgets 取整行，再用 sscanf 配合 %d,%31[^,],%lf 解析。
