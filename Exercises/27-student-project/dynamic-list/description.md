# 动态列表统计

## 题目描述

学生成绩管理系统用一个动态数组保存所有记录。本题实现最小版本：按输入数量申请动态列表，统计人数、平均分和最高分学生。

## 输入格式

第一行整数 n（1..1000）；随后 n 行，每行一个不含空白的姓名（长度 1..31）和一个成绩（双精度，0..100）。

## 输出格式

输出一行：count=<人数> avg=<平均分，保留两位小数> top=<最高分姓名>

## 示例

**示例 1**

输入：

```text
3
Lin 80
Mei 95.5
Kai 88
```

输出：

```text
count=3 avg=87.83 top=Mei
```

## 知识点

- 动态数组是记录的唯一所有者
- 记录数与容量分开维护
- 遍历统计与释放

## 提示

- 记录数在运行时才知道，用 malloc 申请 n 个结构体。
- 平均分等于总分除以 n，保留两位小数。
