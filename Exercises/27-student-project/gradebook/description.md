# 最高分学生

## 题目描述

成绩管理系统需要从一批记录里找出最高分。本题先用结构体数组实现最小版本。

## 输入格式

第一行整数 n（1..100）；随后 n 行，每行一个不含空白的姓名（长度 1..31）和一个整数成绩。

## 输出格式

一行：成绩最高的学生姓名；并列时输出最先出现的那一个。

## 示例

**示例 1**

输入：

```text
3
Lin 80
Mei 95
Kai 88
```

输出：

```text
Mei
```

**示例 2**

输入：

```text
2
A 90
B 90
```

输出：

```text
A
```

## 知识点

- 结构体数组保存记录
- 求最大值与并列处理
- 姓名使用固定长度字符数组

## 提示

- 并列时保留最先出现的学生，因此只在 score > best 时更新。
