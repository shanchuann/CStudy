# 二级指针

## 题目描述

二级指针是指向指针的指针。把二级指针作为参数，函数就能通过 *out 让调用者的指针指向某个对象，这是通过指针参数“返回”指针的常用手法。

请实现 void max_ptr(int **out, int *a, int *b)，让 *out 指向较大的那个整数；两个数相等时指向 a。

## 输入格式

一行两个整数 a、b，用空格分隔。

## 输出格式

输出一行：max=<较大的值>

## 数据范围

-1000000 ≤ a, b ≤ 1000000。

## 示例

**示例 1**

输入：

```text
3 8
```

输出：

```text
max=8
```

**示例 2**

输入：

```text
-5 -2
```

输出：

```text
max=-2
```

## 知识点

- 二级指针：指向指针的指针
- 通过二级指针参数让调用者的指针指向新的对象
- 间接寻址的层级：*out 得到指针，**out 得到整数

## 提示

- 比较的是 *a 与 *b 的值，写入的是 a 与 b 这两个地址。
- 两个数相等时让 *out 指向 a。
