# 返回空指针的查找

## 题目描述

查找函数在找不到目标时需要一个明确的返回值。请实现 int *find(int *values, int n, int target)：找到目标时返回它所在元素的地址，找不到时返回空指针 NULL。

调用者必须先判断返回值是否为 NULL，再解引用；用返回的地址减去数组首地址就能得到下标。

## 输入格式

第一行两个整数 n 与 target；第二行 n 个整数，用空格分隔。

## 输出格式

找到时输出一行：index=<目标第一次出现的下标>

找不到时输出一行：not found

## 数据范围

1 ≤ n ≤ 100，所有元素与 target 的绝对值不超过 10000。

## 示例

**示例 1**

输入：

```text
5 7
1 3 5 7 9
```

输出：

```text
index=3
```

**示例 2**

输入：

```text
4 6
1 3 5 7
```

输出：

```text
not found
```

## 知识点

- 空指针 NULL 表示没有指向任何对象
- 指针作为返回值的契约：调用者必须先检查是否为 NULL
- 用指针减法把地址转换成下标

## 提示

- 找到第一个匹配的元素就立即返回它的地址。
- 不要解引用 NULL：先用 if (hit == NULL) 判断。
