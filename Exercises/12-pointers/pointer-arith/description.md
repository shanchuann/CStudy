# 指针运算

## 题目描述

指向数组元素的指针可以自增，也可以在两个指针之间做减法：相减得到的是它们之间相差的元素个数，而不是字节数。

请用指针遍历数组求和，并用首尾元素的指针相减求出 span。

## 输入格式

第一行一个整数 n；第二行 n 个整数，用空格分隔。

## 输出格式

输出一行：sum=<所有元素之和> span=<首尾元素指针之差>

## 数据范围

1 ≤ n ≤ 100，每个元素的绝对值不超过 10000，总和在 32 位 int 范围内。

## 示例

**示例 1**

输入：

```text
5
1 2 3 4 5
```

输出：

```text
sum=15 span=4
```

**示例 2**

输入：

```text
1
7
```

输出：

```text
sum=7 span=0
```

## 知识点

- 数组名退化为指向首元素的指针
- 用指针自增遍历数组
- 指向同一数组的两个指针相减，得到相差的元素个数

## 提示

- span 是首尾元素指针之差，n 个元素之间有 n - 1 个间隔。
- n 为 1 时首尾指针相同，span 为 0。
