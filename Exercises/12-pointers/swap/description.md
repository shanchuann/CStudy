# 指针交换

## 题目描述

C 语言只有值传递：函数内修改形参不会影响实参。要修改调用者的变量，必须传入变量的地址，在函数内解引用该地址。

请实现 void swap(int *left, int *right)，交换两个整数。

## 输入格式

一行两个整数 a、b，用空格分隔。

## 输出格式

输出一行两个整数：交换后的 a 与 b，用一个空格分隔。

## 数据范围

-1000000 ≤ a, b ≤ 1000000。

## 示例

**示例 1**

输入：

```text
3 8
```

输出：

```text
8 3
```

**示例 2**

输入：

```text
-1 1
```

输出：

```text
1 -1
```

## 知识点

- 值传递：形参只是实参的副本
- 地址传递：用 & 取地址、用 * 解引用修改实参
- 指针参数让函数可以写回调用者的变量

## 提示

- 交换前先把 *left 存进临时变量，否则原值会被覆盖。
- 调用时传入 &a 与 &b。
