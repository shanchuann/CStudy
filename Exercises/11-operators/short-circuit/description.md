# 短路求值

## 题目描述

逻辑与 && 在左操作数为假时不再计算右操作数，逻辑或 || 在左操作数为真时也不再计算右操作数，这称为短路求值。

本题用一个带副作用的函数来观察短路：全局变量 calls 记录 f 被调用的次数，函数 f 每次被调用都让 calls 加一，并返回 1。程序依次计算 (a && f()) 与 (b || f())，然后输出 calls。

## 输入格式

一行两个整数 a、b，只可能是 0 或 1。

## 输出格式

输出一行：calls=<f 被调用的次数>

## 数据范围

a, b 的取值只可能是 0 或 1。

## 示例

**示例 1**

输入：

```text
0 0
```

输出：

```text
calls=1
```

**示例 2**

输入：

```text
0 1
```

输出：

```text
calls=0
```

## 知识点

- 逻辑与 && 与逻辑或 || 的短路求值规则
- 短路使右操作数的副作用不发生
- 用全局计数观察表达式的求值过程

## 提示

- a 为 0 时 a && f() 不会调用 f。
- b 为 1 时 b || f() 不会调用 f。
