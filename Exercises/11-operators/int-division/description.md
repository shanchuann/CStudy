# 整数除法与取余

## 题目描述

C99 起，整数除法向零截断，也就是直接丢弃小数部分；取余的结果符号与被除数相同，并且满足 a == (a / b) * b + a % b。

## 输入格式

一行两个整数 a、b（b 不为 0），用空格分隔。

## 输出格式

输出一行：q=<a / b> r=<a % b>

例如 a = 7、b = 2 时输出 q=3 r=1。

## 数据范围

-10000 ≤ a, b ≤ 10000，且 b 不为 0。

## 示例

**示例 1**

输入：

```text
7 2
```

输出：

```text
q=3 r=1
```

**示例 2**

输入：

```text
-7 2
```

输出：

```text
q=-3 r=-1
```

## 知识点

- 整数除法向零截断：丢弃小数部分
- 取余结果的符号与被除数相同
- 除数为 0 是未定义行为，必须避免

## 提示

- C99 起除法向零截断，取余结果符号与被除数相同。
- -7 / 2 的结果是 -3 而不是 -4。
