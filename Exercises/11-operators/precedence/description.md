# 表达式优先级

## 题目描述

表达式中运算符有优先级，括号可以改变结合顺序。本题要求先计算 a 与 b 的和，再与 c 相乘，即求 (a + b) * c 的值。

同样的三个数，如果写成 a + b * c，因为 * 的优先级高于 +，结果会完全不同。

## 输入格式

一行三个整数 a、b、c，用空格分隔。

## 输出格式

输出一行一个整数：(a + b) * c 的结果。

## 数据范围

-1000 ≤ a, b, c ≤ 1000，结果在 32 位 int 范围内。

## 示例

**示例 1**

输入：

```text
2 3 4
```

输出：

```text
20
```

**示例 2**

输入：

```text
1 -2 5
```

输出：

```text
-5
```

## 知识点

- 运算符优先级与结合性：括号内的子表达式先求值
- 算术运算符 + 与 * 的优先级差异
- 整型表达式的求值与 int 类型的输出

## 提示

- (a + b) * c 与 a + b * c 的结果通常不同，注意括号的作用。
- 输出末尾只有一个换行。
