# 位掩码

## 题目描述

位掩码用一个二进制位表示一种状态。对整数 flags 的第 k 位（从 0 开始计数）可以做四种操作：

- 置 1：flags | (1 << k)
- 清 0：flags & ~(1 << k)
- 翻转：flags ^ (1 << k)
- 检测： (flags >> k) & 1

## 输入格式

一行两个整数 flags 与 k，用空格分隔。

## 输出格式

输出一行：

set=<置 1 后的值> clear=<清 0 后的值> toggle=<翻转后的值> test=<第 k 位的值>

## 数据范围

0 ≤ flags ≤ 255，0 ≤ k ≤ 7。

## 示例

**示例 1**

输入：

```text
0 2
```

输出：

```text
set=4 clear=0 toggle=4 test=0
```

**示例 2**

输入：

```text
5 0
```

输出：

```text
set=5 clear=4 toggle=4 test=1
```

## 知识点

- 按位或 | 置位、按位与 & 清位、按位异或 ^ 翻转
- 左移 1 << k 构造第 k 位的掩码
- 右移后再与 1 相与，检测某一位

## 提示

- ~(1 << k) 会把第 k 位以外的位全部置 1，用它和 flags 相与即可清位。
- test 只取第 k 位的值，不要直接输出 flags >> k。
