# 自增与自减

## 题目描述

后缀自增 x++ 先取出 x 的原值作为表达式的值，再把 x 加 1；前缀自增 ++y 先把 y 加 1，再取出新值作为表达式的值。

本题对同一个输入 n 分别做这两种操作：

int x = n; int post = x++;
int y = n; int pre = ++y;

## 输入格式

一行一个整数 n。

## 输出格式

输出一行：post=<post> pre=<pre> x=<x> y=<y>

其中 post 是 x++ 表达式的值，pre 是 ++y 表达式的值。

## 数据范围

-1000000 ≤ n ≤ 1000000。

## 示例

**示例 1**

输入：

```text
5
```

输出：

```text
post=5 pre=6 x=6 y=6
```

**示例 2**

输入：

```text
-1
```

输出：

```text
post=-1 pre=0 x=0 y=0
```

## 知识点

- 后缀自增 x++ 先取值再自增
- 前缀自增 ++y 先自增再取值
- 自增的副作用与表达式的值

## 提示

- post 保存的是自增前的值，pre 保存的是自增后的值。
- x 与 y 最终都等于 n + 1。
