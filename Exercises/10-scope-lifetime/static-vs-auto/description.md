# 自动与静态存储期

## 题目描述

分别实现两个计数函数，体会自动存储期与静态存储期的区别：

- int next_auto(void)：使用普通局部变量，每次调用都从 0 重新开始，因此总是返回 0。
- int next_static(void)：使用静态局部变量，第一次调用返回 1，第二次返回 2，第三次返回 3。

在 main 中各连续调用三次，按要求格式输出结果。

## 输入格式

无输入。

## 输出格式

输出一行：auto=0 0 0 static=1 2 3

## 示例

**示例 1**

输出：

```text
auto=0 0 0 static=1 2 3
```

## 知识点

- 自动存储期：每次进入函数都重新创建、重新初始化
- 静态存储期：只在程序开始时创建一次，值跨调用保持
- 函数返回后普通局部变量失效，static 局部变量仍然存在

## 提示

- next_auto 每次调用都从 0 开始，所以三次都返回 0。
- next_static 用 static int value = 0; 并在返回前自增。
