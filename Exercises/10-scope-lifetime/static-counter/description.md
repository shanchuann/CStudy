# 静态局部变量

## 题目描述

实现函数 int next_value(void)，借助静态局部变量记录调用次数：第一次调用返回 1，第二次返回 2，第三次返回 3，依此类推。

在 main 中连续调用三次，把三次返回值输出在同一行。静态局部变量只初始化一次，它的值在函数返回后依然保留，这正是它与普通局部变量的区别。

## 输入格式

无输入。

## 输出格式

输出一行：1 2 3

## 示例

**示例 1**

输出：

```text
1 2 3
```

## 知识点

- static 局部变量把存储期延长到整个程序运行期间
- static 局部变量的初始化只在第一次进入函数时执行一次
- 自动存储期变量在每次函数调用时重新创建

## 提示

- 把 value 声明为 static int value = 0;，它就会在多次调用之间保持。
- 不要写成一个 printf 里连续调用三次，因为函数参数的求值顺序未定义，要用三个变量分步调用。
