# 块作用域层次

## 题目描述

用嵌套的块演示块作用域：在 main 中定义 int level = 10;，进入一层内层块后定义同名的 int level = 20;，再进入更深一层块定义 int level = 30;。

在每一层分别输出当前可见的 level 值，观察内层变量如何遮蔽外层变量。

## 输入格式

无输入。

## 输出格式

输出一行：10 20 30

## 示例

**示例 1**

输出：

```text
10 20 30
```

## 知识点

- 块作用域从变量声明处开始，到所在块结束
- 内层块可以定义与外层同名的变量，从而遮蔽外层变量
- 离开内层块后，外层变量重新可见

## 提示

- 用一对花括号 {} 建立内层块，在块内用 int level = 20; 定义同名变量。
- 输出顺序是从最外层向内层：10 20 30。
