# 用函数计算阶乘

## 题目描述

实现函数 int factorial(int n)，返回 n 的阶乘 n!。约定 0! = 1。

函数要有明确的返回类型和返回值，由 main 调用它并输出结果。

## 输入格式

一行一个整数 n（0 ≤ n ≤ 12）。

## 输出格式

输出一个整数，即 n! 的值。

## 示例

**示例 1**

输入：

```text
0
```

输出：

```text
1
```

**示例 2**

输入：

```text
5
```

输出：

```text
120
```

## 知识点

- 函数的定义、返回值与调用
- 用循环累乘实现阶乘
- 0! = 1 这一约定需要单独处理

## 提示

- 累乘变量初值取 1，循环从 2 乘到 n，这样 n 为 0 或 1 时结果自然为 1。
- 12! = 479001600 仍在 int 范围内，用 int 保存即可。
