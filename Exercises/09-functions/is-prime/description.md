# 素数判断

## 题目描述

实现函数 int is_prime(int n)：n 是素数时返回 1，否则返回 0。main 根据返回值输出 prime 或 not prime。

教材中函数常用来把"判断"这类逻辑独立出来，让主程序只关心结果。

## 输入格式

一行一个整数 n（1 ≤ n ≤ 1000000）。

## 输出格式

n 是素数时输出 prime，否则输出 not prime。

## 示例

**示例 1**

输入：

```text
2
```

输出：

```text
prime
```

**示例 2**

输入：

```text
997
```

输出：

```text
prime
```

## 知识点

- 函数返回判断结果（真 / 假）
- 试除法判断素数：检查 2 到 sqrt(n) 之间有无因子
- 循环条件写成 i * i <= n 避免调用开方函数

## 提示

- 小于 2 的数都不是素数，先返回 0。
- 循环条件用 i * i <= n，一旦 n % i == 0 就返回 0。
- 循环正常结束后返回 1。
