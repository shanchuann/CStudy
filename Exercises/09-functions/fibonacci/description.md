# 递归斐波那契

## 题目描述

实现递归函数 int fib(int n)，返回斐波那契数列的第 n 项。约定 fib(0) = 0、fib(1) = 1，当 n 大于等于 2 时 fib(n) = fib(n-1) + fib(n-2)。

要求函数通过调用自身完成计算，并正确设置递归的终止条件。

## 输入格式

一行一个整数 n（0 ≤ n ≤ 30）。

## 输出格式

输出一个整数，即 fib(n)。

## 示例

**示例 1**

输入：

```text
0
```

输出：

```text
0
```

**示例 2**

输入：

```text
7
```

输出：

```text
13
```

## 知识点

- 递归函数的终止条件与递推关系
- 函数调用自身（直接递归）
- 斐波那契数列的定义 fib(0)=0、fib(1)=1、fib(n)=fib(n-1)+fib(n-2)

## 提示

- 先写终止条件：n 为 0 或 1 时直接返回 n。
- n 大于等于 2 时返回 fib(n - 1) + fib(n - 2)。
- n 最大为 30，递归调用次数虽多但在可接受范围内。
