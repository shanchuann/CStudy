# 全局与局部的遮蔽

## 题目描述

C 语言采用"就近可见"的名字查找规则：内层块里定义的同名变量会遮蔽外层变量。被遮蔽的文件作用域变量不能在内层按名字访问，但可以通过一个函数间接读到它。

本题目要求同时观察三层同名变量 `value`：文件作用域的值、main 里的局部值、以及内层块中的值。

## 输入格式

无输入。

## 输出格式

输出一行：global=<文件作用域的值> local=<main 局部变量的值> inner=<内层块中变量的值>

## 示例

**示例 1**

输出：

```text
global=10 local=20 inner=30
```

## 知识点

- 内层块中的同名变量遮蔽外层变量
- 被遮蔽的文件作用域变量无法在块内按名字访问
- 通过函数可以间接访问被遮蔽的全局变量

## 提示

- main 里的 value 遮蔽了文件作用域的 value。
- 内层块结束后，外层的 value 又可见了。
