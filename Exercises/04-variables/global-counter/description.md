# 文件作用域全局变量

## 题目描述

定义在所有函数之外的变量具有文件作用域，它的生命周期贯穿整个程序，并且在程序启动时按写明的初值完成初始化。本题目要求把计数器状态放在文件作用域的全局变量里，再用两个函数读写它。

## 输入格式

一行一个整数 n。

## 输出格式

输出一行：before=<调用 bump 之前 counter 的值> after=<循环 n 次 bump 之后 counter 的值>

## 数据范围

0 <= n <= 1000。

## 示例

**示例 1**

输入：

```text
3
```

输出：

```text
before=0 after=3
```

**示例 2**

输入：

```text
0
```

输出：

```text
before=0 after=0
```

## 知识点

- 文件作用域变量定义在所有函数之外，生命周期是整个程序
- 全局变量在程序启动时按给定初值完成初始化
- 用函数封装对共享状态的访问

## 提示

- counter 定义在所有函数之外，初值为 0。
- bump 不需要参数，直接修改全局变量。
