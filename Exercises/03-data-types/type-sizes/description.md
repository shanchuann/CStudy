# 固定宽度类型与 sizeof

## 题目描述

`<stdint.h>` 提供了固定宽度的整数类型 `int8_t`、`int32_t`、`int64_t`，它们的宽度不随平台变化，因此求出的结果在任何机器上都一样。

`sizeof` 是运算符而不是函数，它在编译期求出一个类型或对象占用的字节数。当它的操作数是数组名时，得到的是整个数组的字节数，不会退化成指针；再除以单个元素的字节数，就得到数组的元素个数。

## 输入格式

无输入。

## 输出格式

输出两行：

fixed=<sizeof(int8_t)> <sizeof(int32_t)> <sizeof(int64_t)>

count=<int arr[8] 的元素个数>

第一行的三个数之间用一个空格分隔。

## 示例

**示例 1**

输出：

```text
fixed=1 4 8
count=8
```

## 知识点

- 固定宽度整数类型 int8_t/int32_t/int64_t 由 <stdint.h> 提供
- sizeof 是运算符而不是函数，在编译期求值
- sizeof(数组)/sizeof(数组[0]) 求元素个数，数组名在 sizeof 中不退化

## 提示

- sizeof 的结果类型是 size_t，先转成 int 再用 %d 输出。
- 数组名出现在 sizeof 中时不会退化成指针。
