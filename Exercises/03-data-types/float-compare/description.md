# 浮点数的比较

## 题目描述

大多数十进制小数在二进制浮点里没有精确表示，例如 0.1 和 0.3 都只是近似值，因此用 `==` 比较两个浮点数往往会得到意外的结果。常见做法是判断两个数之差的绝对值是否小于一个误差限。

## 输入格式

两行，每行一个双精度浮点数 a、b。

## 输出格式

输出两行：

exact=<a == b 直接比较的结果，1 或 0>

approx=<|a - b| < 1e-9 的结果，1 或 0>

## 数据范围

-1e6 <= a, b <= 1e6。

## 示例

**示例 1**

输入：

```text
1.0
1.0
```

输出：

```text
exact=1
approx=1
```

**示例 2**

输入：

```text
0.3
0.30000000000000004
```

输出：

```text
exact=0
approx=1
```

## 知识点

- 二进制浮点无法精确表示大多数十进制小数
- 不要用 == 直接判断两个浮点数是否相等
- 用误差限 epsilon 比较浮点数

## 提示

- 求绝对值不要用 math.h 的 fabs，用条件表达式自己算。
- 1e-9 只是本题数值范围内的宽松误差限。
