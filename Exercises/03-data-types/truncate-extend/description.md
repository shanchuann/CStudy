# 截取与扩充

## 题目描述

把一个取值范围更大的整数赋给取值范围更小的整数类型时，超出部分会被截取掉，只保留低位；反过来，把短类型赋给长类型时会做扩充。

当目标类型是无符号类型时，转换规则是"按 2 的幂取模"：`(unsigned char)n` 的结果就是 n mod 256，负数也一样。这是标准规定好的行为，不是未定义行为。

## 输入格式

一行一个整数 n。

## 输出格式

输出一行，三个用空格分隔的字段：

low=<把 n 转换成 unsigned char 后的值> mid=<把 n 转换成 unsigned short 后的值> wide=<再把 low 赋给 unsigned int 后的值>

## 数据范围

-100000 <= n <= 100000。

## 示例

**示例 1**

输入：

```text
300
```

输出：

```text
low=44 mid=300 wide=44
```

**示例 2**

输入：

```text
-1
```

输出：

```text
low=255 mid=65535 wide=255
```

## 知识点

- 长类型赋给短类型时只保留低位字节，高位被截取
- 短类型赋给长类型时按目标类型的规则扩充
- 有符号数转无符号数按模 2 的 n 次幂取值，是标准规定的行为

## 提示

- (unsigned char)n 的结果等价于 n mod 256。
- wide 必须由 low 再赋给 unsigned int 得到，而不是直接由 n 转换。
