# fseek/ftell 随机访问

## 题目描述

二进制文件中的定长记录可以用 fseek 直接定位：第 k 条记录从偏移 k * sizeof(记录) 处开始，不必从头顺序读完。

程序要求：

1. 读入 n 和 n 个 32 位整数，用 fwrite 以二进制方式全部写入 data.bin；
2. 重新以 "rb" 方式打开 data.bin，用 fseek 定位到第 k 条记录（从 0 开始编号）并读出；
3. 用 fseek 到文件末尾配合 ftell 求出文件的总字节数。

判题在临时目录中运行，可以直接在当前目录创建 data.bin。

## 输入格式

第一行：整数 n（1..100）。

第二行：n 个整数，用空格分隔。

第三行：整数 k（0 <= k < n）。

## 输出格式

输出一行：value=<第 k 个整数> size=<文件总字节数>

## 数据范围

1 <= n <= 100，每个整数在 32 位 int 范围内。

## 示例

**示例 1**

输入：

```text
3
10 20 30
1
```

输出：

```text
value=20 size=12
```

**示例 2**

输入：

```text
1
7
0
```

输出：

```text
value=7 size=4
```

## 知识点

- 固定宽度记录的二进制读写
- fseek 的字节偏移与 SEEK_SET / SEEK_END
- ftell 与文件大小的关系
- 二进制模式下不做换行转换

## 提示

- 第 k 条记录的偏移是 k * sizeof(int32_t)。
- 文件总字节数可以先 fseek 到 SEEK_END 再 ftell。
