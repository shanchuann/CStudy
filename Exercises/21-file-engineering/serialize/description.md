# 逐字段序列化

## 题目描述

跨平台的数据交换通常使用文本格式：把每个字段按固定格式写进文件，读回时再逐字段解析，而不是把结构体整体写进文件（结构体布局和对齐因平台而异）。

程序要求：

1. 读入一条学生记录，用 fprintf 按 id|name|score 的格式写入 student.txt（score 保留一位小数）并关闭；
2. 重新打开 student.txt，用 fscanf 逐字段读回 id、name、score；
3. 输出读回的内容。

判题在临时目录中运行，可以直接在当前目录创建 student.txt。

## 输入格式

一行：整数 id、不含空白的姓名（长度 1..31）、成绩（实数），用空格分隔。

## 输出格式

输出一行：id=<id> name=<name> score=<成绩，保留一位小数>

## 示例

**示例 1**

输入：

```text
7 Lin 95.5
```

输出：

```text
id=7 name=Lin score=95.5
```

**示例 2**

输入：

```text
1 A 0
```

输出：

```text
id=1 name=A score=0.0
```

## 知识点

- fprintf / fscanf 文本序列化
- 用 %[^|] 读取到分隔符为止的字段
- 不要把结构体整体写入文件（跨平台格式不同）

## 提示

- 写文件后要 fclose，再重新 fopen 读取。
- 读回姓名用 %31[^|]，它读到 '|' 就停止。
