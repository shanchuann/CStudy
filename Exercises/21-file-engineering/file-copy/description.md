# 二进制文件拷贝

## 题目描述

二进制文件拷贝必须用 fread / fwrite 按字节处理，不能使用字符串函数，因为文件内容里可能包含 '\0'。

程序要求：

1. 读入一行文本（不含行尾换行），用 "wb" 方式把它的每个字节写入 src.bin，关闭文件；
2. 再用 "rb" 方式读出 src.bin 的全部字节，用 "wb" 方式写入 dst.bin；
3. 最后逐字节比较 src.bin 与 dst.bin 的内容。

判题在临时目录中运行，可以直接在当前目录创建 src.bin 与 dst.bin。

## 输入格式

一行文本，长度 0..200，可以包含空格。行尾的换行符不属于文件内容。

## 输出格式

输出一行：bytes=<字节数> equal=<yes|no>

其中字节数是写入 src.bin 的字节个数；两个文件内容完全相同时 equal 为 yes，否则为 no。

## 数据范围

输入行长度 0..200。

## 示例

**示例 1**

输入：

```text
ABC
```

输出：

```text
bytes=3 equal=yes
```

**示例 2**

输入：

```text
cstudy
```

输出：

```text
bytes=6 equal=yes
```

## 知识点

- fopen 的 "wb" / "rb" 二进制模式
- fread / fwrite 的返回值与元素个数
- 二进制拷贝不能用字符串函数
- fclose 的返回值也要检查

## 提示

- 判题在临时目录运行，直接在当前目录创建 src.bin 与 dst.bin 即可。
- 写完之后要用 fclose 关闭再重新打开读取，否则读不到刚写入的内容。
- 比较时用 memcmp 逐字节比较，长度取两个文件字节数的较小值再判断是否相等。
