# 冒泡排序

## 题目描述

读入 n 个整数，用冒泡排序把它们按升序排列。

冒泡排序重复地比较相邻的两个元素，如果前一个比后一个大就交换它们。每完成一趟，当前未排序区间里最大的元素就被"冒"到了区间末尾，因此内层循环的上界可以逐趟减小。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）。

第二行 n 个整数，用空格分隔。

## 输出格式

输出一行，为升序排序后的 n 个整数，相邻两个数之间用一个空格分隔，行尾只有一个换行。

## 数据范围

1 ≤ n ≤ 100，每个整数的绝对值不超过 100000。

## 示例

**示例 1**

输入：

```text
5
3 1 4 1 5
```

输出：

```text
1 1 3 4 5
```

**示例 2**

输入：

```text
3
-1 -2 -3
```

输出：

```text
-3 -2 -1
```

## 知识点

- 冒泡排序：相邻两个元素比较，逆序就交换
- 每趟结束后最大的元素被冒到区间末尾
- 内层循环上界随趟数递减，循环不变量是末尾 i 个元素已就位
- 重复元素和已有序数组同样要正确处理

## 提示

- 外层控制趟数，内层比较 values[j] 与 values[j + 1]。
- 已经有序的数组不需要提前退出也能得到正确结果。
