# 归并排序

## 题目描述

读入 n 个整数，用递归的归并排序把它们按升序排列。

归并排序是典型的分治算法：把区间分成两半，分别递归排序，再把两个已经有序的子区间合并起来。合并时两个子区间的首元素就是各自剩余部分的最小值，比较它们并把较小的那个放进辅助数组即可。递归的停止条件是区间长度小于 2。

推荐用半开区间 [left, right) 表示待排序范围，这样空区间和单元素区间都能自然处理。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 1000）。

第二行 n 个整数，用空格分隔。

## 输出格式

输出一行，为升序排序后的 n 个整数，相邻两个数之间用一个空格分隔，行尾只有一个换行。

## 数据范围

1 ≤ n ≤ 1000，每个整数的绝对值不超过 100000。

## 示例

**示例 1**

输入：

```text
6
5 2 4 1 3 6
```

输出：

```text
1 2 3 4 5 6
```

**示例 2**

输入：

```text
4
4 3 2 1
```

输出：

```text
1 2 3 4
```

## 知识点

- 分治三步：拆分、递归求解、合并结果
- 递归函数必须有停止条件：区间长度小于 2 时直接返回
- 合并两个已经有序的区间，只需比较各自当前的首元素
- 区间用半开区间 [left, right) 表示，合并需要辅助数组

## 提示

- 递归函数 merge_sort(values, buffer, left, right) 处理半开区间。
- 合并完成后要把 buffer 中排好的部分复制回 values。
