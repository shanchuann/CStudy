# 奇偶判断

## 题目描述

读入一个整数，判断它是偶数还是奇数。注意 C 语言中负数取余的结果仍然是负数，例如 -3 % 2 等于 -1，所以判断奇数不能写“余数等于 1”。

## 输入格式

一行整数。

## 输出格式

偶数输出 even，奇数输出 odd。

## 示例

**示例 1**

输入：

```text
4
```

输出：

```text
even
```

**示例 2**

输入：

```text
-3
```

输出：

```text
odd
```

## 知识点

- if / else 双分支选择
- % 取余运算判断整除
- 负数取余的结果仍然是负数（-3 % 2 等于 -1）

## 提示

- 判断 value % 2 == 0 就输出 even。
- 不要写成 value % 2 == 1，负数取余会得到 -1。
