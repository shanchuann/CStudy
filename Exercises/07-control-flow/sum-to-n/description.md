# 从一加到 N

## 题目描述

读入整数 n，计算 1 + 2 + ... + n 的和。可以用 for 循环从 1 累加到 n。

## 输入格式

一行整数 n，1 <= n <= 65535。

## 输出格式

输出一行，表示累加和。

## 示例

**示例 1**

输入：

```text
5
```

输出：

```text
15
```

**示例 2**

输入：

```text
65535
```

输出：

```text
2147450880
```

## 知识点

- for 循环与累加求和
- 循环变量的初值与边界控制
- int 的取值范围：65535 的累加和仍在 int 内

## 提示

- 用 for 循环从 1 加到 n。
- 65535 的累加和是 2147450880，没有超过 int 的最大值。
