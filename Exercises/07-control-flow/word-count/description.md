# 有限状态机统计单词

## 题目描述

读入一行文本，统计字符数和单词数。连续的非空白字符算作一个单词，空白字符（空格、制表符等）分隔单词。可以用有限状态机的思路：用一个标记记录当前是否处在单词内部，状态从“不在单词内”变为“在单词内”时单词数加一。

## 输入格式

一行文本，长度不超过 200，以换行结束。

## 输出格式

输出一行：words=单词数 chars=字符数，其中字符数不含行尾的换行符。

## 示例

**示例 1**

输入：

```text
hello world
```

输出：

```text
words=2 chars=11
```

**示例 2**

输入：

```text
  
```

输出：

```text
words=0 chars=2
```

## 知识点

- 有限状态机：用 in_word 标记当前是否在单词内部
- getchar 逐字符读入，遇到换行或 EOF 结束
- 空白字符与非空白字符的判断

## 提示

- 用一个 in_word 变量记录当前是否在单词内部。
- 读到换行或文件结束就停止；换行不计入字符数。
