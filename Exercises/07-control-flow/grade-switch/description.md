# switch 分级

## 题目描述

按百分制分数给出等级：90 到 100 为 A，80 到 89 为 B，70 到 79 为 C，60 到 69 为 D，0 到 59 为 F，其他输入为 invalid。要求把分数除以 10 之后用 switch 分组判断。

## 输入格式

一行整数分数，可能是任意整数。

## 输出格式

输出一行：A、B、C、D、F 或 invalid。

## 示例

**示例 1**

输入：

```text
95
```

输出：

```text
A
```

**示例 2**

输入：

```text
59
```

输出：

```text
F
```

**示例 3**

输入：

```text
101
```

输出：

```text
invalid
```

## 知识点

- switch / case / default 多分支选择
- 整数除法把分数分成 10 分一档
- 边界值的处理（100 与 0 都不能漏）

## 提示

- 先判断分数是否在 0..100 之外，范围外直接输出 invalid。
- 用 switch (score / 10)，case 10 和 case 9 都输出 A。
