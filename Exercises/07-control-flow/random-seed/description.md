# srand 的确定性

## 题目描述

rand() 生成伪随机数，srand(seed) 用来设置种子。同一个种子会得到完全相同的序列，不同的种子通常得到不同的序列，所以 rand() 不适合安全用途。本题要求验证这两点：用种子 2024 生成两组序列 A、B，用种子 1 生成序列 C。

## 输入格式

一行整数 n，1 <= n <= 1000。

## 输出格式

输出两行：

repeat=A 与 B 逐元素都相同则为 yes，否则为 no

differ=A 与 C 至少有一个元素不同则为 yes，否则为 no

## 示例

**示例 1**

输入：

```text
8
```

输出：

```text
repeat=yes
differ=yes
```

## 知识点

- rand 与 srand：伪随机数生成器与种子
- 同一种子产生完全相同的序列
- 不同种子通常产生不同序列；伪随机数不能用于安全用途

## 提示

- 分别调用 srand(2024)、srand(2024)、srand(1) 生成三组序列。
- 只比较序列是否一致，不要输出随机数的具体值。
