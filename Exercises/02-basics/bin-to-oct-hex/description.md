# 二进制分组转八进制与十六进制

## 题目描述

二进制与八进制、十六进制之间的转换可以按位分组：从右向左每 3 位一组得到八进制，每 4 位一组得到十六进制，不足一组时在左侧补 0。

例如 1111 分成一组 1111 得到十六进制 F，补一位分成 001 111 得到八进制 17。

## 输入格式

一行只含 0 和 1 的字符串，长度 1..32，允许前导零。

## 输出格式

输出两行：

oct=<八进制，不含前导零>

hex=<十六进制，使用大写字母，不含前导零>

数值为 0 时输出 oct=0 与 hex=0。

## 示例

**示例 1**

输入：

```text
1111
```

输出：

```text
oct=17
hex=F
```

**示例 2**

输入：

```text
100000000
```

输出：

```text
oct=400
hex=100
```

## 知识点

- 二进制与八进制：从右向左每 3 位一组
- 二进制与十六进制：从右向左每 4 位一组
- 位权与除基取余

## 提示

- 可以先把二进制转成 unsigned long long，再用除 8、除 16 取余得到结果。
- 十六进制用大写字母 A-F。
