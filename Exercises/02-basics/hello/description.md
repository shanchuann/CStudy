# 输出 Hello World

## 题目描述

编写一个 C 程序，在标准输出上打印一行文字 Hello World。

这是第一个练习，重点不是输出内容本身，而是熟悉一个完整的 C 源程序结构：预处理指令、main 函数和标准库函数调用。教材中最小程序的四个组成部分（#include、main、语句、return）在这里都会出现。

## 输入格式

无输入。

## 输出格式

输出一行：Hello World

## 示例

**示例 1**

输出：

```text
Hello World
```

## 知识点

- C 源程序结构：预处理指令、main 函数、语句与 return
- printf 标准输出与换行符
- 从源代码到可执行文件的编译运行过程

## 提示

- 输出末尾只有一个换行，不要多打印空行。
- main 的返回值 0 表示程序正常结束。
