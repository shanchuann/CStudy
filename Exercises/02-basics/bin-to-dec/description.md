# 二进制转十进制

## 题目描述

把一行二进制字符串转换成十进制整数。教材中“其他进制转换为十进制”的方法是：把每一位乘以对应的位权再求和。例如 1010 表示 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 10。

## 输入格式

一行只含 0 和 1 的字符串，长度 1..31，允许前导零。

## 输出格式

一行：对应的十进制整数。

## 示例

**示例 1**

输入：

```text
1010
```

输出：

```text
10
```

**示例 2**

输入：

```text
1111111111111111111111111111111
```

输出：

```text
2147483647
```

## 知识点

- 按位权展开求和
- 字符到数字的转换 ch - '0'
- 用 long long 避免溢出

## 提示

- 从左到右读每一位：value = value * 2 + (ch - '0')。
- 31 位全 1 正好是 int 的最大值。
