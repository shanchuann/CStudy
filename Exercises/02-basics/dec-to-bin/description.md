# 十进制转二进制

## 题目描述

把一个十进制非负整数转换为二进制。教材给出的方法是“除 2 取余，逆序排列”：不断用 2 去除，记录每次的余数，直到商为 0，再把余数从后往前排列。

## 输入格式

一行一个整数 n，满足 0 <= n <= 65535。

## 输出格式

一行：n 的二进制表示，不含前导零。n = 0 时输出 0。

## 示例

**示例 1**

输入：

```text
10
```

输出：

```text
1010
```

**示例 2**

输入：

```text
255
```

输出：

```text
11111111
```

## 知识点

- 进制转换：除 2 取余、逆序排列
- 数组暂存余数
- 循环与整除

## 提示

- 先把余数按从低到高存入数组，再倒序输出。
- n = 0 是特殊情况，直接输出 0。
