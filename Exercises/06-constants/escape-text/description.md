# 转义字符

## 题目描述

本题练习转义字符和字符串字面量。请输出四行固定内容，体会制表符、双引号、反斜杠和百分号在 C 字符串中的写法。

## 输入格式

无输入。标准输入中即使有内容也请忽略。

## 输出格式

输出四行，每行以换行结束：

- 第 1 行：大写字母 A 与 B 之间有一个制表符
- 第 2 行：一对双引号包围大写字母 C
- 第 3 行：文本 C:\dir\file，其中的反斜杠是普通字符
- 第 4 行：文本 100%，其中的百分号是普通字符

## 示例

**示例 1**

输出：

```text
A	B
"C"
C:\dir\file
100%
```

## 知识点

- 转义字符：制表符、双引号、反斜杠在字符串字面量中的写法
- printf 的格式串中输出一个百分号要写成两个百分号
- 字符串字面量以换行结束一次输出

## 提示

- 制表符、双引号和反斜杠都需要用转义字符表示。
- 百分号不是转义字符，但在 printf 的格式串里要写成两个。
