# const 常量与圆的周长面积

## 题目描述

用 const 定义一个只读的圆周率常量 PI = 3.141592653589793，读入半径 r，计算圆的周长和面积。const 对象在定义后不能通过标识符修改，适合表示这种固定常量。

## 输入格式

一行实数 r，满足 0 < r <= 1000。

## 输出格式

输出一行：c=周长 s=面积，两个数值都保留两位小数，中间用一个空格分隔。

## 示例

**示例 1**

输入：

```text
1
```

输出：

```text
c=6.28 s=3.14
```

**示例 2**

输入：

```text
0.5
```

输出：

```text
c=3.14 s=0.79
```

## 知识点

- const 修饰的只读对象：定义后不能通过标识符修改
- 用 const 定义圆周率常量并参与浮点计算
- %.2f 保留两位小数输出

## 提示

- 周长是 2 * PI * r，面积是 PI * r * r。
- 不要使用 math.h，四则运算就够了。
