# 字符常量与 ASCII

## 题目描述

字符常量在 C 语言中的类型是 int，它的值就是字符的编码。读入一个可打印的非空白 ASCII 字符，输出它的编码，以及编码加一后对应的字符。

例如字符 A 的编码是 65，编码 66 对应字符 B。

## 输入格式

一个可打印的非空白 ASCII 字符，例如 A、a 或 0。

## 输出格式

输出一行，格式为 code=编码 next=下一个字符，两部分之间用一个空格分隔。

## 示例

**示例 1**

输入：

```text
A
```

输出：

```text
code=65 next=B
```

**示例 2**

输入：

```text
0
```

输出：

```text
code=48 next=1
```

## 知识点

- 字符常量的类型是 int，它的值就是字符的编码
- %c 按字符输出，%d 按整数编码输出
- ASCII 表中相邻字符的编码是连续的

## 提示

- 用 getchar() 读入一个字符，返回值就是它的编码。
- next 部分是编码加一后对应的字符。
