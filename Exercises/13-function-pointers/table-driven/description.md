# 表驱动计算器

## 题目描述

把函数指针放进数组，就可以用下标选择要执行的函数，用查表代替一长串分支，这就是表驱动。

请用函数指针数组实现四则运算：+ 表示加、- 表示减、* 表示乘、/ 表示整数除法。

## 输入格式

一行：一个运算符字符（+、-、*、/）与两个整数 a、b，之间用空格分隔。

## 输出格式

输出一行整数结果；当运算符未知，或运算符为 / 且除数为 0 时，输出一行：error

## 数据范围

-10000 ≤ a, b ≤ 10000，b 可以为 0（此时只有 / 会输出 error）。

## 示例

**示例 1**

输入：

```text
+ 3 4
```

输出：

```text
7
```

**示例 2**

输入：

```text
/ 8 2
```

输出：

```text
4
```

## 知识点

- 函数指针数组：int (*table[4])(int, int)
- 表驱动：用下标查表代替一长串 if/else
- 通过数组元素调用函数指针

## 提示

- 可以用 strchr("+-*/", op) 求出运算符在表中的下标。
- 先判断运算符是否合法，再判断除数是否为 0。
