# 比较函数

## 题目描述

比较函数是一种典型的回调：它约定返回负数表示第一个参数应排在前面，返回 0 表示两者相等，返回正数表示第一个参数应排在后面。把比较函数作为参数传给排序算法，就能在不改动算法的前提下切换升序与降序。

请实现冒泡排序 void sort(int *values, int n, int (*cmp)(int, int))，以及两个比较函数：

- int ascending(int a, int b)：升序
- int descending(int a, int b)：降序

## 输入格式

第一行两个整数 n 与 order（order 为 1 表示升序，-1 表示降序）；第二行 n 个整数，用空格分隔。

## 输出格式

输出一行排序后的 n 个整数，用一个空格分隔。

## 数据范围

1 ≤ n ≤ 100，每个元素的绝对值不超过 10000。

## 示例

**示例 1**

输入：

```text
5 1
3 1 4 1 5
```

输出：

```text
1 1 3 4 5
```

**示例 2**

输入：

```text
5 -1
3 1 4 1 5
```

输出：

```text
5 4 3 1 1
```

## 知识点

- 比较函数的契约：返回负数、0、正数
- 把函数指针作为参数传给算法
- 冒泡排序中由 cmp 决定是否交换

## 提示

- 用 (a > b) - (a < b) 写出升序比较，可以避免两数相减溢出。
- 当 cmp(values[j], values[j + 1]) > 0 时交换相邻元素。
