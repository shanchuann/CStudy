# 回调函数

## 题目描述

函数名在表达式中会退化为指向该函数的指针，因此函数指针可以作为参数传入另一个函数，由调用者决定“做什么”。这种被传入的函数就叫回调函数。

请实现 int apply(int (*operation)(int, int), int a, int b)，它用函数指针调用传入的函数并返回结果。程序用 apply 调用 add，完成加法。

## 输入格式

一行两个整数 a、b，用空格分隔。

## 输出格式

输出一行一个整数：a + b 的结果。

## 数据范围

-1000000 ≤ a, b ≤ 1000000，结果在 32 位 int 范围内。

## 示例

**示例 1**

输入：

```text
4 5
```

输出：

```text
9
```

**示例 2**

输入：

```text
-1 1
```

输出：

```text
0
```

## 知识点

- 函数指针的声明与赋值
- 函数名在表达式中退化为函数指针
- 通过函数指针调用函数（回调）

## 提示

- apply 的函数体只需要 return operation(a, b);。
- 调用时把函数名 add 当作实参传给 apply。
