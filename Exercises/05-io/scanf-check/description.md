# 检查 scanf 的返回值

## 题目描述

`scanf` 的返回值是成功转换并赋值的参数个数，用它可以在读入之后立刻判断输入是否合法。如果返回值和期望的参数个数不一致，就不应该使用那些没有被赋值的变量。

## 输入格式

一行。可能是两个整数，也可能是别的内容。

## 输出格式

如果成功读入两个整数，输出它们的和；否则输出 invalid。

## 示例

**示例 1**

输入：

```text
3 4
```

输出：

```text
7
```

**示例 2**

输入：

```text
abc
```

输出：

```text
invalid
```

## 知识点

- scanf 的返回值是成功转换并赋值的参数个数
- 用返回值做输入校验
- 输入不匹配时 scanf 会提前返回

## 提示

- scanf("%d %d", &a, &b) 返回 2 才算两个整数都读到了。
- 读失败时不要使用 a、b 的值。
