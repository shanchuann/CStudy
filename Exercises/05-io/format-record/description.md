# 格式化输入输出

## 题目描述

`scanf` 用 `%s` 读入一段不含空白的字符串，用 `%d` 读入十进制整数；`printf` 则按格式串把字面量和转换结果拼起来输出。本题练习把读到的名字和分数按指定格式重新输出。

## 输入格式

一行：一个不含空白字符的名字（长度 1..63）和一个整数分数，中间用空格分隔。

## 输出格式

输出一行：name: score（冒号后面有一个空格）。

## 数据范围

-1000000 <= score <= 2147483647。

## 示例

**示例 1**

输入：

```text
Lin 95
```

输出：

```text
Lin: 95
```

**示例 2**

输入：

```text
A 0
```

输出：

```text
A: 0
```

## 知识点

- scanf 用 %s 读入不含空白的字符串
- scanf 用 %d 读入十进制整数
- printf 把字面量与转换说明符拼成输出

## 提示

- 输出格式是 name: score，冒号后面有一个空格。
- 读字符串要加宽度限制，防止写越界。
