# 温度转换

## 题目描述

华氏温度与摄氏温度的换算公式是 F = C * 9 / 5 + 32。注意在 C 语言里 9 / 5 是两个整数相除，结果是 1，所以必须让参与运算的数至少有一个是浮点数。

## 输入格式

一行一个摄氏温度（双精度浮点数）。

## 输出格式

输出一行华氏温度，保留两位小数。

## 数据范围

-1000 <= C <= 1000。

## 示例

**示例 1**

输入：

```text
0
```

输出：

```text
32.00
```

**示例 2**

输入：

```text
100
```

输出：

```text
212.00
```

## 知识点

- scanf 用 %lf 读入 double
- printf 用 %.2f 控制小数位数
- 整数除法 9/5 会截断成 1

## 提示

- 写成 9.0 / 5.0 或先乘后除，避免整数除法。
- 输出只保留两位小数，末尾只有一个换行。
