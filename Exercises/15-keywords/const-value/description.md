# const 只读对象

## 题目描述

const 关键字把对象声明为只读：它和普通变量一样有类型、有存储空间，但定义之后不能再被赋值，因此必须在定义时初始化。

请定义两个 const 对象，一个保存整数 42，一个保存小数 3.14，并按规定的格式输出它们。

## 输入格式

无输入。

## 输出格式

输出一行：value=42 pi=3.14

## 示例

**示例 1**

输出：

```text
value=42 pi=3.14
```

## 知识点

- const 修饰对象表示只读，必须在定义时初始化
- const 对象和普通变量一样参与表达式与输出
- %.2f 控制小数的输出位数

## 提示

- const int value = 42; 与 const double pi = 3.14; 都要在定义处给出初值。
- 输出格式严格为 value=42 pi=3.14，pi 用 %.2f 输出。
