# sizeof 与数组长度

## 题目描述

sizeof 是运算符而不是函数，它在编译期求出类型或对象占用的字节数。当操作数是数组名时，sizeof 得到的是整个数组的字节数，而不是指针的大小；把整个数组的字节数除以一个元素的字节数，就得到元素个数。

请定义 int arr[8];，输出定宽整数类型的大小和数组的元素个数。

## 输入格式

无输入。

## 输出格式

输出两行：

fixed=1 4 8

count=8

第一行依次是 int8_t、int32_t、int64_t 的 sizeof，用空格分隔；第二行是 arr 的元素个数。

## 示例

**示例 1**

输出：

```text
fixed=1 4 8
count=8
```

## 知识点

- sizeof 是编译期运算符而不是函数
- 数组名作为 sizeof 的操作数时不退化为指针
- 用 sizeof(arr) / sizeof(arr[0]) 求元素个数
- stdint.h 的定宽整数类型 int8_t / int32_t / int64_t

## 提示

- sizeof 的结果转成 int 之后再用 %d 输出，避免 %zu 带来的可移植性问题。
- 定宽类型的 sizeof 由标准保证：int8_t 为 1、int32_t 为 4、int64_t 为 8。
