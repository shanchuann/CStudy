# C11 关键字与 _Static_assert

## 题目描述

C11 引入了 _Static_assert，它在编译期检查一个常量表达式：条件不成立就报错、编译失败，条件成立则不生成任何运行时代码。它常用来确认类型大小、结构体布局等编译期前提。

请用 _Static_assert 断言 sizeof(int32_t) == 4 与 sizeof(int64_t) == 8，并用 _Bool 保存一个真值；编译通过时输出 ok。

## 输入格式

无输入。

## 输出格式

输出一行：ok

## 示例

**示例 1**

输出：

```text
ok
```

## 知识点

- _Static_assert 在编译期检查常量表达式
- 断言失败时编译直接报错，通过则继续编译
- _Bool 是 C99 起的布尔类型，取值 0 或 1

## 提示

- 写法：_Static_assert(表达式, "错误信息"); 两个断言分别检查 int32_t 与 int64_t 的大小。
- 断言在编译期生效，所以程序能编译通过就说明两个大小都正确，直接输出 ok 即可。
