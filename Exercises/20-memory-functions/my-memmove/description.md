# 自定义 memmove

## 题目描述

memcpy 不保证源和目标重叠时的复制结果，memmove 则必须正确处理重叠：当目标地址小于源地址时从前往后复制，否则从后往前复制。

请实现：

```c
void *my_memmove(void *dst, const void *src, size_t count);
```

主程序读入一个单词，用 my_memmove 把从第二个字符开始的内容左移到开头，再把原来的首字符放到末尾，最后输出移动后的字符串。

## 输入格式

一行一个不含空白的单词，长度 2..30。

## 输出格式

输出一行：整体左移一位后的字符串。

## 数据范围

单词长度 2..30。

## 示例

**示例 1**

输入：

```text
abcd
```

输出：

```text
bcda
```

**示例 2**

输入：

```text
hello
```

输出：

```text
elloh
```

## 知识点

- 重叠区域的复制方向
- memmove 与 memcpy 的区别
- 指针大小比较决定复制顺序

## 提示

- dst < src 时从前往后复制，否则从后往前复制。
- dst == src 或 count 为 0 时什么也不用做。
