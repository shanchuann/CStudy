# 反转链表

## 题目描述

按输入顺序用尾插法建立一条动态单链表，然后用迭代方式原地反转它，最后按反转后的顺序输出所有节点的值。

原地反转只允许修改节点之间的 next 指针，不允许新建节点，也不允许只交换节点里的数据来伪造结果。推荐使用三个指针：previous 指向前一个节点，current 指向当前节点，next 临时保存当前节点的后继。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）。

第二行 n 个整数，用空格分隔。

## 输出格式

输出一行，为反转后各节点的值，相邻两个值之间用一个空格分隔，行尾只有一个换行。

## 数据范围

1 ≤ n ≤ 100，每个整数的绝对值不超过 100000。

## 示例

**示例 1**

输入：

```text
4
1 2 3 4
```

输出：

```text
4 3 2 1
```

**示例 2**

输入：

```text
1
9
```

输出：

```text
9
```

## 知识点

- 迭代反转使用 previous / current / next 三个指针
- 每步先保存后继，再改 current->next 指向 previous
- 反转结束后头指针要更新为原来的尾节点
- 原地反转不新建节点，只修改 next 指针

## 提示

- 循环体里的三步顺序不能乱：存后继、改指向、整体前移。
- 反转完成后原来的头节点变成了尾节点，它的 next 应该是 NULL。
