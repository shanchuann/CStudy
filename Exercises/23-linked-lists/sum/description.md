# 链表求和

## 题目描述

从标准输入读取 n 个整数，按输入顺序用尾插法建立一条动态单链表：每读到一个数就用 malloc 分配一个节点，把新节点接在当前表尾之后。建表完成后遍历链表求所有节点值之和，最后把每个节点都 free 掉。

本题的重点是链表的三件套：头指针初始化、尾插时维护表尾、遍历结束后完整释放。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）。

第二行 n 个整数，用空格分隔。

## 输出格式

输出一行，为链表中所有节点值之和。

## 数据范围

1 ≤ n ≤ 100，每个整数的绝对值不超过 100000，和不超过 32 位 int 范围。

## 示例

**示例 1**

输入：

```text
4
1 2 3 4
```

输出：

```text
10
```

**示例 2**

输入：

```text
1
-5
```

输出：

```text
-5
```

## 知识点

- 节点结构体：数据域 value 与指针域 next
- 头指针必须初始化为 NULL 表示空链表
- 尾插建表：保存尾指针，把新节点接到表尾
- 遍历链表与逐节点 free，不要使用已释放的内存

## 提示

- 头指针一开始是 NULL，尾插时第一个节点要同时更新 head。
- 释放节点前先把 next 存到临时变量，否则会丢失后继。
