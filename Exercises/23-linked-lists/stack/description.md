# 括号匹配（数组栈）

## 题目描述

用数组实现一个容量为 100 的栈，判断输入的括号串是否匹配。

扫描字符串：遇到左括号 ( [ { 就压栈；遇到右括号 ) ] } 时，如果栈为空则一定不匹配，否则弹出栈顶并检查它是否是对应的左括号。扫描结束后，只有栈为空才说明所有括号都配对了。

## 输入格式

一行字符串，长度 1 到 100，只包含 ( ) [ ] { } 六种字符，没有空格。

## 输出格式

输出一行：匹配时输出 balanced，否则输出 unbalanced。

## 数据范围

字符串长度 1 ≤ len ≤ 100，数组栈容量固定为 100。

## 示例

**示例 1**

输入：

```text
()
```

输出：

```text
balanced
```

**示例 2**

输入：

```text
(]
```

输出：

```text
unbalanced
```

## 知识点

- 栈的后进先出：push 压栈、pop 出栈，只操作栈顶
- 左括号入栈，右括号与栈顶匹配后出栈
- 栈空时遇到右括号说明不匹配
- 扫描结束后栈必须为空才算匹配

## 提示

- 数组栈需要同时维护栈顶下标（或 size）和容量。
- 输入长度不超过 100，容量 100 的数组栈足够。
