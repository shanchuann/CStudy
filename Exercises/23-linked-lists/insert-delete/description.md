# 链表删除节点

## 题目描述

按输入顺序用尾插法建立一条动态单链表，然后删除第一个值等于 x 的节点。如果链表中不存在值为 x 的节点，链表保持不变。最后按原来的相对顺序输出剩余节点的值。

删除时要注意三种位置：目标在表头、目标在表尾、目标在中间。无论哪一种，都要先保存前驱（或者使用二级指针直接改写链接），再 free 被摘下的节点，不要留下悬空指针。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）。

第二行 n 个整数，用空格分隔。

第三行一个整数 x，表示要删除的值。

## 输出格式

输出一行，为删除后链表中剩余节点的值，相邻两个值之间用一个空格分隔，行尾只有一个换行。

如果删除后链表为空，输出 empty。

## 数据范围

1 ≤ n ≤ 100，每个整数的绝对值不超过 100000。

## 示例

**示例 1**

输入：

```text
4
1 2 3 4
2
```

输出：

```text
1 3 4
```

**示例 2**

输入：

```text
1
7
7
```

输出：

```text
empty
```

## 知识点

- 删除节点必须找到它的前驱并让前驱跳过它
- 用二级指针 Node **link 统一处理删除头节点与中间节点
- 删除后 free 被摘下的节点，并保持其余节点顺序不变
- 只删除第一个匹配的节点

## 提示

- 链表为空、删除头节点、删除尾节点、找不到目标，这四种情况都要走通。
- 摘链的顺序是：保存被删节点，改链接，再 free。
