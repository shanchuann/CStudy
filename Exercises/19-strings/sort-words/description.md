# 字符串排序

## 题目描述

把 n 个单词按字典序升序输出。用二维字符数组保存单词，用 strcmp 比较大小，用 strcpy 交换内容。

## 输入格式

第一行一个整数 n（1 ≤ n ≤ 50）；随后 n 行每行一个不含空白的单词，长度 1..32。

## 输出格式

按字典序升序输出 n 行，每行一个单词。

## 示例

**示例 1**

输入：

```text
3
banana
apple
cherry
```

输出：

```text
apple
banana
cherry
```

**示例 2**

输入：

```text
2
b
a
```

输出：

```text
a
b
```

## 知识点

- 二维字符数组保存多个字符串
- strcmp 的返回值与字典序（按 unsigned char 比较）
- 交换字符串内容要用 strcpy 加一个临时数组

## 提示

- strcmp(a, b) > 0 表示 a 排在 b 后面，需要交换。
- 交换时借助一个临时字符数组，不要只交换某个字符。
