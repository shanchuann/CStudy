# 字符串反转

## 题目描述

把读入的单词原地反转：用两个下标分别从头和尾向中间移动，交换字符，直到两者相遇。

## 输入格式

一行一个不含空白的单词，长度 1..100。

## 输出格式

输出反转后的单词。

## 示例

**示例 1**

输入：

```text
hello
```

输出：

```text
olleh
```

**示例 2**

输入：

```text
a
```

输出：

```text
a
```

## 知识点

- 字符串以 '\0' 结尾，长度用 strlen 得到
- 双指针从两端向中间交换实现原地反转
- scanf 的 %s 加宽度限制可以安全读入单词

## 提示

- 用 strlen 求出长度，下标从 0 到 len - 1。
- 循环条件是 left < right，长度为 1 或偶数时都不会越界。
