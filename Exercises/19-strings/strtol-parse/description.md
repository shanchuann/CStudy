# strtol 安全解析

## 题目描述

用 strtol 安全地解析一行文本：允许前导空白和可选的正负号；解析结束后跳过尾随空白，end 指针应当正好停在字符串末尾；结果还必须落在 int 的表示范围内。以上任何一条不满足都视为 invalid。

空串、完全没有数字、数字后面还跟着非空白字符、数值超出 int 范围，都算 invalid。

## 输入格式

一行长度 1..32 的文本。

## 输出格式

解析成功输出 int=<值>，否则输出 invalid。

## 示例

**示例 1**

输入：

```text
  -42  
```

输出：

```text
int=-42
```

**示例 2**

输入：

```text
12abc
```

输出：

```text
invalid
```

## 知识点

- strtol 的 end 指针告诉我们解析停在哪里
- errno 与 ERANGE：数值超出 long 的表示范围
- 区分“没有解析出数字”和“数字后面还有垃圾”
- limits.h 中的 INT_MIN / INT_MAX

## 提示

- end == 输入起点，说明根本没有解析出数字。
- 用 long 接收结果，再检查它是否落在 INT_MIN..INT_MAX 之内。
- 解析后跳过尾随空白，指针必须停在字符串末尾。
