# fgets 安全读取

## 题目描述

fgets 带容量参数，是读取一行文本的安全方式，但换行符也会被一起读进缓冲区。请读入一行文本，去掉行末的换行符后原样输出，注意行首和行尾的空格都要保留。

## 输入格式

一行文本，长度不超过 100，可以包含空格。

## 输出格式

输出这一行本身（去掉行末换行符），其它字符原样保留。

## 示例

**示例 1**

输入：

```text
hello world
```

输出：

```text
hello world
```

**示例 2**

输入：

```text
  keep spaces  
```

输出：

```text
  keep spaces  
```

## 知识点

- fgets 需要容量参数，读到换行或缓冲区满为止
- fgets 会把行末的换行符一起读进来，需要自己去掉
- 为什么不要用 gets

## 提示

- fgets 的第二个参数是缓冲区大小，最多读入 size - 1 个字符。
- 只去掉行末的换行符，行首和行尾的空格都要保留。
