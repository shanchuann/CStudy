# 字符串化与两层展开

## 题目描述

# 运算符把宏参数变成字符串字面量，而且这个参数不会被提前展开。想让宏先展开再字符串化，需要再套一层宏。请定义下面三个宏：

    #define STR(x) #x
    #define XSTR(x) STR(x)
    #define VALUE 42

输入中的整数只用于演示字符串化，它的数值本身不参与计算。

## 输入格式

一行一个整数 n。

## 输出格式

输出两行：

text=<STR(n) 的结果>

value=<XSTR(VALUE) 的结果>

## 示例

**示例 1**

输入：

```text
7
```

输出：

```text
text=n
value=42
```

**示例 2**

输入：

```text
0
```

输出：

```text
text=n
value=42
```

## 知识点

- # 运算符把宏参数变成字符串字面量
- 宏参数在被字符串化之前不会被展开
- 两层宏（STR / XSTR）实现先展开再字符串化

## 提示

- STR(n) 得到的是参数本身的文本，而不是它保存的值。
- XSTR(VALUE) 会先把 VALUE 展开成 42，再字符串化。
